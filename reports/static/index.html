7.1 Statistical Analysis
ทดสอบว่าปริมาณน้ำฝนและอุณหภูมิสัมพันธ์กับอัตราการเติบโตของการระบาดในอีก 4 สัปดาห์ข้างหน้าหรือไม่
สมมติฐานทางสถิติ
สมมติฐาน H₀ (ไม่มีผล) H₁ (มีผล — ต้องผ่านทั้งหมด) ผล
H1 — ฝน ฝนไม่สัมพันธ์กับการเติบโตของการระบาด ค่าสหสัมพันธ์ ≥ 0.10 ใน อย่างน้อย 2 จาก 5 ช่วงเวลาที่ทดสอบ (ล่วงหน้า 0–4 สัปดาห์) ไม่ผ่าน
H2 — อุณหภูมิ อุณหภูมิสูงสุด/ต่ำสุดไม่สัมพันธ์กับการเติบโตของการระบาด ค่าสหสัมพันธ์ ≥ 0.10 และทิศทาง (+/−) ต้องตรงกันใน ≥ 4 จาก 5 ปีทดสอบ ไม่ผ่าน
H4 — ความแม่นยำ โมเดลที่ใช้อากาศพยากรณ์ได้แม่นเท่ากับโมเดลที่ไม่ใช้ โมเดลที่เพิ่มข้อมูลอากาศลดค่าความผิดพลาด ≥ 5% ใน ≥ 4 จาก 5 ปีทดสอบ โดย confidence interval ไม่คร่อมศูนย์ ไม่ผ่าน
วิธีทางสถิติที่ใช้
Partial Spearman Correlation (H1/H2)
วัดความสัมพันธ์ระหว่าง ความผิดปกติของฝน/อุณหภูมิในสัปดาห์ก่อนหน้า 0–4 สัปดาห์ กับ อัตราการเติบโตของผู้ป่วยในอีก 4 สัปดาห์ข้างหน้า หลังหักอิทธิพลของ ระดับการระบาดปัจจุบัน ออก — ป้องกันการที่ตัวแปรอากาศดูเหมือนสัมพันธ์เพราะระดับโรคสูงอยู่แล้ว
Block-Week Bootstrap (H4)
สุ่มตัวอย่างข้อมูลเป็นบล็อกทีละสัปดาห์ 100 รอบ เพื่อคำนวณ confidence interval 95% ของส่วนต่างความผิดพลาด — บล็อกตามสัปดาห์เพราะจังหวัดในสัปดาห์เดียวกันมักติดโรคพร้อมกัน (ระบาดเป็นคลื่น)
ขนาดผลกระทบ (Effect Size)
ค่าสหสัมพันธ์ต่ำกว่า 0.10 ถือว่าเล็กมาก (เทียบเกณฑ์ Cohen); ส่วนลดความผิดพลาดต่ำกว่า 5% ไม่มีนัยสำคัญเชิงปฏิบัติ — ทั้งสองเกณฑ์กำหนดก่อนดูผล
ค่าสหสัมพันธ์สูงสุด (absolute) ต่อตัวแปรอากาศและปีทดสอบ — เส้นแดง = เกณฑ์ผ่านที่ 0.10
7.2 Machine Learning Model
ทำนายอัตราการเติบโตของผู้ป่วยไข้เลือดออกในอีก 4 สัปดาห์ข้างหน้า ระดับจังหวัด
Algorithm ที่เลือกและเหตุผล
Model บทบาท เหตุผลเลือก
Huber Regression หลัก (H4) Linear model ที่ทนต่อค่าผิดปกติ เหมาะกับ target ที่มีหางยาว; tuned ด้วย inner cross-validation ก่อนดูผล test
Elastic Net ตรวจสอบ Linear model + คัดตัวแปรอัตโนมัติ ใช้ตรวจว่า Huber ไม่ overfitting
Gradient Boosting (HistGBR) ตรวจสอบ Tree-based จับความสัมพันธ์ไม่เชิงเส้น; ทีม DS พบว่า tree ทำงานได้ดีกว่า linear
XGBoost / TabNet-Mini ตรวจสอบ เปรียบเทียบผลข้ามทีม (ทีม DS: XGBoost ลด 4.24%, TabNet ลด 2.44%)
การแบ่งข้อมูลและการตั้งค่า
Train / Test: Expanding window 5 รอบ — รอบแรก train ปี 2016–2018 ทดสอบปี 2019; รอบสุดท้าย train ปี 2016–2024 ทดสอบปี 2025; เว้นช่วง 4 สัปดาห์ระหว่าง train และ test เพื่อไม่ให้ label ของ train รั่วไหลเข้า test
Hyperparameter Tuning: ค้นหาค่าที่ดีที่สุดด้วย inner cross-validation 5-fold บน train แต่ละรอบ; ล็อกค่าที่ได้ (ความทนต่อ outlier = 1.35, ค่า regularization = 1.0) ก่อนเปิดดูผล test
ค่าความผิดปกติของอากาศ: คำนวณจาก "ค่าปกติตามฤดูกาล" ของ train เท่านั้นในแต่ละรอบ — ป้องกันการรั่วไหลจากปีทดสอบ
Metric หลัก: MAE = ค่าเฉลี่ยความผิดพลาดสัมบูรณ์ของ log-growth ของอัตราป่วย — ตีความง่ายกว่า RMSE ซึ่งลงโทษค่าผิดปกติหนักเกินไป
MAE ต่อปีทดสอบ: โมเดล Baseline (ประวัติ+ฤดูกาล) vs โมเดลที่เพิ่มข้อมูลอากาศ — Huber Regression
7.3 Time-Series Analysis
วิเคราะห์รูปแบบตามเวลา ตรวจสอบ Seasonality และเปรียบเทียบวิธีพยากรณ์
ลักษณะของชุดเวลา
ช่วงเวลา: ม.ค. 2016 – ธ.ค. 2025 · 527 สัปดาห์ · 77 จังหวัด · 40,579 จุดข้อมูล
Seasonality: รอบปีชัดเจน (~52 สัปดาห์); ยอดระบาดมักเดือน ก.ค.–ก.ย.; จับได้ด้วย sine/cosine 3 คู่ (ครอบคลุมรอบ 1 ปี, 6 เดือน, 4 เดือน)
Trend: ไม่มี trend ระยะยาว แต่มีความผิดปกติระดับปี (2021 ต่ำมาก/COVID, 2023 ระบาดใหญ่); 66% ของ variance มาจากคลื่นระดับประเทศ ไม่ใช่จังหวัดแต่ละแห่ง
Stationarity: target ถูกนิยามเป็น log(อัตราป่วย 4 สัปดาห์หน้า) − log(อัตราป่วย 4 สัปดาห์ที่ผ่านมา ซึ่งเป็นการ difference เพื่อให้ค่าวนรอบศูนย์และไม่ drift ตามเวลา; ใช้ ARIMA(1,1,1) ซึ่งมี I=1 รองรับ unit root
Autocorrelation: ค่าในสัปดาห์นี้สัมพันธ์กับสัปดาห์ก่อนอย่างมีนัย — ARIMA ต่อจังหวัด (3 พารามิเตอร์) ทำได้ดีกว่า ML ที่รวมทุกจังหวัดพร้อมกัน
วิธีพยากรณ์และการประเมิน
ARIMA Walk-Forward: fit โมเดลบน train แล้วอัปเดต state ด้วยค่าจริงก่อนพยากรณ์แต่ละจุด (เทียบได้กับ ML ที่เห็นข้อมูลถึงสัปดาห์ปัจจุบัน); พยากรณ์ล่วงหน้า 4 สัปดาห์
SARIMA Open-Loop: พยากรณ์จากจุดสิ้นสุด train โดยไม่ใช้ค่าจริงใน test เลย — เสมือนนำโมเดลไปใช้งานจริงโดยไม่อัปเดต; MAE สูงกว่าเพราะ state สะสมความผิดพลาด
ARIMAX+ฝน (Oracle): ARIMA + ปริมาณฝนในสัปดาห์ก่อน 0–4 สัปดาห์; ใส่ค่าฝนจริงของอนาคต 4 สัปดาห์ให้โมเดลด้วย (oracle = รู้ล่วงหน้า ทำได้เฉพาะในงานวิจัย); ถ้าฝนไม่ช่วยแม้รู้ล่วงหน้า แสดงว่าฝนไม่มีผลจริง
Metric: MAE เดียวกับ ML · Train/Test แบ่งตาม fold เดียวกัน ไม่สุ่ม
อัตราป่วยเฉลี่ยต่อปี (เฉลี่ยข้ามทุกจังหวัดและสัปดาห์) — แสดงความผิดปกติปี 2023 และ 2019
จุดผิดปกติและ Change Point: ปี 2021 การระบาดต่ำผิดปกติ (อาจเพราะ COVID lockdown ลด exposure กับยุง) — แยกออกเป็นปีทดสอบสำรอง ไม่นับในการตัดสิน · ปี 2023 ระบาดใหญ่สุดในชุดข้อมูล (บางจังหวัดสูงกว่าค่าเฉลี่ยถึง 2 เท่า) · ปีทดสอบแรก (2019) ทุกโมเดลมีความผิดพลาดสูงกว่าปีอื่น เพราะ train ใช้ข้อมูลเพียง 3 ปี (2016–2018 เท่านั้น)
